# Bible Reader content — SW-Swahili

This repository contains the Bible Reader SD-card content for **SW-Swahili**.

## Directory layout

- `text/SW-Swahili/` — all Bible translations and their original nested folder structure.
- `audio/SW-Swahili/` — audio Bible book folders and chapter MP3s.
- `gospel/SW-Swahili/` — Gospel files, retaining original names such as `Gospel.txt` and `Gospel.mp3`.

Copy these folders into the root of the Bible Reader `SDCARD` staging directory.
Do not rename files or flatten directories: the firmware expects the original paths.
